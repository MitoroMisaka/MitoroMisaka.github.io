## 核心工具

![Hermes Agent 架构概览](https://raw.githubusercontent.com/nous-hermes/hermes-agent/main/assets/hermes-architecture.svg)

Hermes Agent 提供以下核心工具：

| 工具 | 用途 |
|------|------|
| `delegate_task` | 分发任务给子 agent，并行执行 |
| `cronjob` | 定时任务调度，可设间隔或 cron 表达式 |
| `terminal` | 执行 shell 命令，支持后台运行 |
| `memory` | 持久化记忆，跨 session 共享事实 |
| `skill_manage` | 创建/更新/删除 skill，固化操作约束 |

## 并行编排

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as 父 Agent
    participant A as 子 Agent A
    participant B as 子 Agent B

    U->>P: 执行 Phase 4+5+6
    P->>A: delegate_task(Phase 4)
    P->>B: delegate_task(Phase 5)
    A-->>P: Phase 4 完成
    B-->>P: Phase 5 完成
    P->>A: delegate_task(Phase 6)
    A-->>P: Phase 6 完成
    P->>U: 全部完成
```

## 定时任务

```ts title="cronjob 创建示例"
// 每 30 分钟检查一次 API 余额
cronjob({
  action: "create",
  name: "cc-usage-check",
  schedule: "30m",
  prompt: "查询 Command Code API 余额并报告",
  toolsets: ["terminal", "web"],
});
```
